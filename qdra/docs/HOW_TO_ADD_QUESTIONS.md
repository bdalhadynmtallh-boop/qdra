# كيفية إضافة أسئلة الأقسام

يحتوي المشروع حاليًا على 262 قسمًا معرّفًا في `src/data/sectionsMeta.ts`،
لكن أسئلة كل قسم توضع يدويًا في ملفات JSON منفصلة داخل:

```
src/data/sections/section001.json
src/data/sections/section002.json
...
src/data/sections/section262.json
```

- رقم الملف يجب أن يتكوّن دائمًا من 3 خانات (001، 002، ...، 262).
- أي قسم لا يملك ملفًا سيظهر تلقائيًا في الموقع بعلامة "قريبًا" وعدد أسئلة 0،
  ولن يكون قابلاً للفتح حتى تتم إضافة ملفه.
- بمجرد إضافة الملف بالاسم الصحيح، سيظهر القسم وأسئلته تلقائيًا في الموقع
  دون الحاجة لأي تعديل إضافي في الكود (يتم تحميل الملفات ديناميكيًا).

## شكل ملف القسم

كل ملف عبارة عن مصفوفة (Array) من الأسئلة بالشكل التالي:

```json
[
  {
    "id": 1,
    "question": "نص السؤال هنا",
    "options": ["الاختيار الأول", "الاختيار الثاني", "الاختيار الثالث", "الاختيار الرابع"],
    "correctIndex": 0,
    "explanation": "شرح الإجابة الصحيحة وسبب صحتها (يظهر عند الإجابة الخاطئة)",
    "questionImage": "/images/sections/003-q1.png",
    "explanationImage": "/images/sections/003-q1-explain.png",
    "passage": "نص قطعة القراءة (اختياري - يُستخدم في أسئلة استيعاب المقروء فقط)"
  }
]
```

### توضيح الحقول

| الحقل | إلزامي؟ | الوصف |
|---|---|---|
| `id` | نعم | رقم تسلسلي للسؤال داخل القسم (يبدأ من 1) |
| `question` | نعم | نص السؤال |
| `options` | نعم | مصفوفة من 4 اختيارات نصية |
| `correctIndex` | نعم | فهرس الإجابة الصحيحة داخل `options` (0 = الأول، 1 = الثاني...) |
| `explanation` | مستحسن | نص الشرح الذي يظهر عند الإجابة الخاطئة |
| `questionImage` | اختياري | مسار صورة توضع أعلى نص السؤال |
| `explanationImage` | اختياري | مسار صورة توضع أسفل نص الشرح |
| `passage` | اختياري | نص قطعة قرائية تظهر أعلى السؤال (لأسئلة استيعاب المقروء) |

## أين توضع الصور؟

ضع أي صور خاصة بالأسئلة داخل مجلد `public/images/` مثلاً:

```
public/images/sections/003-q1.png
```

ثم أشر إليها داخل ملف JSON بالمسار `/images/sections/003-q1.png`.

## أسماء الأقسام وفئاتها

أسماء الأقسام وفئاتها (302 التناظر اللفظي / إكمال الجمل / الخطأ السياقي /
المفردة الشاذة / استيعاب المقروء) معرّفة تلقائيًا في:

```
src/data/sectionsMeta.ts
```

يمكنك تعديل الأسماء أو الفئات أو ترتيب الدورة حسب حاجتك من هذا الملف مباشرة.
